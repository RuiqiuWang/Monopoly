# 新手教程功能

## 启动状态

游戏根目录使用 `.monopoly_state.json` 保存是否运行过游戏：

```json
{
  "has_run": 1
}
```

文件不存在、无法读取或内容无效时按首次运行处理。首次启动会询问：

```text
是否进行新手教程？[Y/N]:
```

输入 `Y`（大小写均可）进入教程，输入 `N` 跳过。首次询问后状态立即写为 `1`，以后启动不会重复询问。

## 教程界面

教程每页按以下顺序渲染：

1. 地图
2. 三行规则介绍
3. 最底部输入提示

共有三页规则。输入空格进入下一页；最后一页按空格退出教程并进入原有游戏流程。输入其他字符会停留在当前页并重新提示。

当前三页是规则占位内容，涵盖掷骰移动、房产购买与租金、特殊地块和胜利条件，后续可以替换为正式规则文本。

## 构建和测试

```powershell
mingw32-make CC=gcc tutorial_test game_engine
.\tutorial_test.exe
```

`tutorial_test.c` 验证状态文件中 `has_run` 的 0/1 写入和读取。手动验证首次教程时可以删除 `.monopoly_state.json`，然后运行：

```powershell
.\game_engine.exe
```
